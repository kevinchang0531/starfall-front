# 星隕戰線 Starfall Front（網頁版）

原創科幻即時戰略遊戲（Godot 4.7）：採礦、蓋基地、研發科技、指揮三陣營部隊，打六章戰役或四種難度的遭遇戰。
參考即時戰略遊戲的玩法類型；陣營、單位、故事與美術全部原創。

**開始玩**：https://kevinchang0531.github.io/starfall-front/

- 操作：滑鼠左鍵選取、拖曳框選，右鍵移動與攻擊；Q／W／E 等快捷鍵（建議用電腦玩，尚不支援觸控）
- 進度（玩家、戰役、戰績、存檔）存在瀏覽器，同一台電腦、同一個瀏覽器下次可接著玩
- 連線對戰需要桌面版（瀏覽器不支援直接連線）
- 美術：OpenAI gpt-image-2 生成；音效音樂：程式合成
